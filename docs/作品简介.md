# 研途牛马秘书 · 作品简介（投稿用）

> 可直接粘贴到活动表单。全部内容基于当前仓库的真实状态：**能用的标"已可用"，没做的标"计划中"**。

---

## 面向谁

**研究生、科研新人、需要长期自我管理的学生。**

他们的时间被导师派活、组会、投稿 DDL、实验跑批、读文献、改论文切得很碎，
痛点不是"没有工具"，而是**工具太分散**：日历管 DDL、便签记组会、闹钟提醒喝水、
文件夹里翻论文版本、周末再花两小时回忆这周干了什么。

---

## 解决什么问题

把上述碎片收敛成**一个常驻桌面的轻量入口**，四个关键设计：

1. **模糊时间**：年 / 季 / 月 / 周 / 日 / 具体时段 / 待安排七级精度，
   「下周把初稿给导师」不会被日历硬塞成某天 9 点。
2. **提醒与计划绑定**：改了时间，提醒自动跟着改，不会按老时间空响。
3. **AI 有边界**：模型只产出**草案建议**，必须点「执行」才落库；**锁定的计划 AI 碰不到**。
4. **低打扰**：全屏时自动静默、免打扰时段、提醒去重、桌宠主动搭话限频。

## 主要功能

| 模块 | 状态 | 说明 |
|---|---|---|
| **日程管理** | 已可用 | 七级时间精度；目标/项目/阶段/里程碑/任务五类节点与父子关系；截止日、优先级、锁定、进度；三栏时间规划中心（年/季/月/周/日/甘特六尺度，缩放平移、拖拽改期、冲突标记、待安排池）；未来五天滚动精细规划（默认 5 天 / 30 分钟粒度） |
| **健康管理** | 已可用 | 喝水、连续工作休息、午晚饭点提醒；自定义频率、免打扰时段、全屏自动静音、锁屏休眠感知；提醒去重、可推迟、重启不重复 |
| **桌宠放松** | 已可用 | 透明置顶角色，呼吸/摇摆/点头/眨眼/多套表情；快捷面板、托盘、缩放、位置记忆；开机问候并汇报五天安排；专注模式 |
| **AI 规划** | 已可用 | 自然语言建/改/删计划、五天规划建议、冲突与风险分析、情景推演；模型优先、规则兜底，只建议不直接执行 |
| **护眼 / 久坐提醒** | 计划中 | 复用现有健康调度器扩展规则 |
| **番茄钟** | 计划中 | 桌宠专注计时可视化 |
| **指定文件管理** | 计划中 | 按目录/规则归档、检索、快捷打开、变更提醒 |
| **个人周报** | 计划中 | 从任务完成、提醒执行、文件变更聚合生成本地周报，支持预览编辑 |

## 目前取得的成果

已经在自己的机器上**日常使用**的 DSH 插件（不是原型页面）：

- 本地规划引擎 + 桌面客户端 + 插件三部分跑通，日程、提醒、桌宠、AI 四个模块可用；
- 服务端 **35 个端到端用例全部通过**（真实 HTTP、真实 SQLite、真实鉴权）；
- 实机长期运行稳定：桌宠约 190 MB、空闲约 3% 单核，引擎约 57 MB；
- 所有数据本地 SQLite，服务只监听 `127.0.0.1`，密钥文件仅本人可读。

---

## 亮点

1. **真实高频场景**：不是想象的痛点，是读研时每天都在处理的事。
2. **一体化不臃肿**：日历、提醒、桌宠、AI 共用一个数据库，改一处全部同步。
3. **低打扰**：全屏静音、免打扰时段、提醒去重、主动搭话限频。
4. **AI 有边界**：只建议、不越权，执行权在用户手里。
5. **隐私友好**：本地存储、本地引擎，不往外传数据。
