## 一、面向谁

**研究生、科研新人、需要长期自我管理的学生。**

这群人的时间被切成很多碎片：导师临时派活、组会、投稿 DDL、实验跑批、读文献、改论文，
再加上「一坐三小时忘了喝水」的日常。他们的痛点不是"没有工具"，而是**工具太分散**：
日历管 DDL、便签记组会、闹钟提醒喝水、文件夹里翻论文版本、周末再花两小时回忆这周干了啥。

「研途牛马秘书」想做的，是把这些**收敛成一个常驻桌面的轻量入口**——不用切软件，抬头就能看见、点一下就能记。

---

## 二、解决什么问题

| 真实场景 | 现在的问题 | 牛马秘书怎么做 |
|---|---|---|
| 「下周三下午留给论文修改」 | 日历只能记精确时刻，想不到几点就没法录 | 支持**模糊时间**：年/季/月/周/日/时段/待安排七级精度，「下周」不会被硬塞成某天 9 点 |
| 「导师说月底前给初稿」 | 只在脑子里记着，越拖越慌 | 截止日自动进入**风险检测**，进度低 + 临近截止会提前提示 |
| 「一坐三小时」 | 手机闹钟太粗暴，还总被打断 | 桌宠用**角色动作 + 气泡**提醒喝水/休息，可设免打扰时段，全屏时不打扰 |
| 「计划赶不上变化」 | 改完时间，提醒还停在旧时间 | 提醒与计划**绑定同步**：改时刻原地更新，换日期自动撤销重建 |
| 「不想被 AI 乱改计划」 | 一些工具会"自作主张" | AI 只能**生成建议（草稿）**，必须点「执行」才落库；**锁定的计划 AI 不可改** |
| 「复盘全靠回忆」 | 一周过去想不起干了什么 | 所有计划变更、完成、提醒都有记录，为周报打底（见路线图） |

## 三、主要功能（五大模块）

**1）日程管理 · 已可用**
七级时间精度（年/季/月/周/日/具体时段/待安排）、目标-项目-阶段-里程碑-任务五类节点与父子关系、
截止日期、优先级、锁定、进度；**三栏时间规划中心**：多尺度时间轴（年/季/月/周/日/甘特）、
平滑缩放、拖拽改期、冲突标记、待安排池；**未来五天滚动精细规划**（默认 5 天 / 30 分钟粒度，可配置）。

**2）健康管理 · 已可用**
喝水（默认 120 分钟）、连续工作休息（50 分钟 + 10 分钟）、午晚饭点提醒；
支持自定义频率、免打扰时段、**全屏应用自动静音**、锁屏/休眠感知；
提醒有唯一键去重、可推迟、服务重启后补发一次且不重复。

**3）桌宠放松 · 已可用**
透明置顶的桌面角色（分层骨骼动画：呼吸/摇摆/点头/眨眼/四套表情/特效），
单击快捷面板、双击规划中心、右键菜单、托盘、滚轮缩放、位置记忆；
状态由真实事件驱动（待机/问候/思考/说话/规划/提醒/开心/专注/休眠/异常），
开机登录主动问候并汇报未来五天安排；专注模式 45 分钟。

**4）指定文件管理 · 路线图（未实现）**
按目录/规则归档、检索、快捷打开、变更提醒。当前版本**不含**该模块。

**5）数据收集与个人周报 · 路线图（未实现）**
基于已有变更/完成/提醒记录生成周报，支持预览编辑。当前版本**不含**周报输出。

**贯穿能力 · 已可用**
本地 AI（DeepSeek）：自然语言建/改/删计划、五天规划建议、冲突与风险分析、情景推演；
**模型优先 + 规则兜底**，模型只输出结构化操作、不直接执行；全部数据存本地 SQLite，只监听 127.0.0.1。

## 四、目前取得的成果

**已经是一个能每天用的、装在 DSH 里的真实插件**，不是原型页面：

- **代码规模**：本地引擎 9 个模块约 6,700 行（Node 24 + 内置 `node:sqlite`，**零 npm 依赖**）；
  桌宠/规划中心 WPF 客户端约 3,000 行 PowerShell；DSH 插件负责编排与 4 个 Agent 工具。
- **测试**：服务端 **35 个端到端用例全通过**（真实起 HTTP + 真实 SQLite + 真实鉴权），
  覆盖模糊时间、锁定保护、提醒幂等与重启补发、snooze、依赖成环、导入导出、AI 降级等。
- **真机验证**：Win10 26200；桌宠常驻内存 186–202 MB、空闲 CPU 2.85% 单核；
  引擎 57 MB、0.07% 单核；已连续多日在自己机器上日常使用。
- **兼容性**：适配 DSH 44.7.0（`tools` 服务改用 `ctx.inject` 等待挂载），
  附带一键自检脚本 `tools/selfcheck.ps1`（15 项检查，升级后跑一次即可定位问题）。
- **工程化**：数据库 WAL + 导出/导入备份、日志分级、单实例保护、断线自动重连、崩溃护栏。

**踩过并修掉的真 bug（都写进了测试/文档）**：改期后提醒不跟着变、DELETE 被当成 POST（405）、
桌宠回复被 `MaxHeight` 裁断、模型返回空操作覆盖规则结果、专注状态跨夜不结束导致"连续工作 757 分钟"。

## 五、亮点（为什么值得投）

1. **真实高频场景**：不是想象的痛点，是我自己在读研时每天要处理的。
2. **一体化但不臃肿**：日历 / 提醒 / 桌宠 / AI 共用一个数据库，改一处全部同步。
3. **低打扰**：全屏静音、免打扰时段、提醒去重、桌宠主动搭话限频。
4. **AI 有边界**：只建议、不越权；锁定的计划模型碰不到；执行权在用户手里。
5. **隐私友好**：本地 SQLite + 本地引擎，只监听回环地址；密钥文件仅本人可读、不进日志、不进导出。
